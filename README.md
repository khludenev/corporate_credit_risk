# corporate_credit_risk
This project explores Probability of Default Modelling for [a synthetic Kaggle dataset](https://www.kaggle.com/datasets/sergionefedov/credit-risk-dataset-50k-loans-10-sectors) containing individual corporate loans using ML algorithms. The `corporate_loans_classification.ipynb` file contains the notebook with the full workflow of exploratory data analysis, hyperparameter tuning and performance evaluation.
The goal of this project is to estimate the probabilities of default for corporate loans based on a set of borrower characteristics such as industry sector, rating, financial ratios etc. To classify the loans, I implemented Logistic Regression, Decision Tree, k-Nearest Neighbors, a blend of LR and kNN, and XGBoost. I cross-validated algorithms with Grid Search basing on ROC-AUC score, I also tuned the threshold maximizing the F1-score. To evaluate the models performance, I calculated confusion matrices, accuracy, precision, recall, F1-score, ROC-AUC, log loss, made a series of additional plots. As the results, XGBoost algorithm demonstrates the highest scores with ROC-AUC=0.818 on validation set, outperforming the blend of the LR and kNN models (ROC-AUC=0.807), it also achieves the highest F1-score among other models. The further improving may require additional features initially unavailable in this dataset.
