# corporate_credit_risk
This project explores Probability of Default Modelling for [a synthetic Kaggle dataset](https://www.kaggle.com/datasets/sergionefedov/credit-risk-dataset-50k-loans-10-sectors) containing individual corporate loans using ML classification algorithms. The `corporate_loans_classification.ipynb` file contains the notebook with the full workflow of exploratory data analysis, hyperparameter tuning and performance evaluation.
The goal of this project is to build a pipeline to estimate the probabilities of default for corporate loans based on a set of borrower characteristics such as industry sector, rating, financial ratios etc. To classify the loans, I implemented Logistic Regression as a baseline model, Decision Tree, k-Nearest Neighbors, a voting algorithm for LR and kNN, and Gradient Boosting. I cross-validated algorithms with Grid Search basing on ROC-AUC score, I also tuned the threshold in order to maximize the F1-score. To evaluate the models performance, I calculated confusion matrices, classification metrics, plotted ROC-AUC curve, made a series of additional plots that can help interpret the results. 
As the results, LightGBM and CatBoost demonstrated the highest scores with ROC-AUC=0.819 on validation set, outperforming the blend of the LR and kNN models (ROC-AUC=0.807), it also achieves the highest F1-score among other models. The further improving may require additional features initially unavailable in this dataset.
